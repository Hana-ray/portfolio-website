# Portfolio Website

## Overview
This is my personal portfolio website built using HTML, CSS, and JavaScript. It introduces my background, skills, projects, and contact information. I created this website as part of my scholarship portfolio to show my learning progress and front-end development skills.

## Features
- About Me section
- Projects section
- Contact section
- Profile photo
- Clickable email link
- Clickable GitHub link
- Clean and responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## What I Learned
- How to structure a webpage using HTML
- How to style a webpage using CSS
- How to organize project files clearly
- How to publish a project with GitHub Pages
- How to create a portfolio website for professional presentation
